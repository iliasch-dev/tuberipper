<p align="left">
 Tuberippepr is a scrapper script for youtube using Selenium to navigate through a list of selected channels and scrap the latest video posted from each channel (either Live or Videos tab) in the form of mp3. Once the video is scrapped it is stored in a database as an entry so as to avoid scrapping it again. You may run it as a scheduled cronjob.
</p>
